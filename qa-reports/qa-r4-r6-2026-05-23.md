## What's good (all 3 agents converged on these)

- Pure functions in `flagSearch.ts` / `flagUpdates.ts` — easy to test, defensive parsing.
- 47 new tests across the three feature test files; LRU trim regression test from R5 demonstrates engineering intent.
- `updateSeqRef` request-id gating in `refreshUpdateCount` is exactly right.
- `acknowledgeUpdates` snapshots `trackedFlagsRef.current` BEFORE await — explicit defense.
- Per-user AsyncStorage keys (`@accessmap/notification_prefs_v1:{userId}`, `@accessmap/flag_last_seen_v1:{userId}`) prevent cross-user leakage.
- `mountedRef` cleanup in `NotificationPrefsModal.load()` is correct.
- Notification prefs default-true on missing fields — backward-compatible with old client writes.
- All-prefs-false: `diffUpdates` drops every update via `isNotifiable` → updateCount=0, banner hidden.
- Sibling-Modal pattern (Fragment wrap) avoids the nested-modal Android flakiness — verified in PhotoLightboxModal mount.

## Polish plan (PL7–PL9)

### PL7 — Critical: a11y + state-correctness fixes

| Finding | Fix |
|---|---|
| Toggle race (correctness #1, edge cases #2/#3) | Use functional `setPrefs(prev => ...)` inside `handleToggle`; persist after the synchronous state update commits. |
| Lightbox stays open on parent close (correctness #2, edge cases #1) | Add `useEffect(() => { if (!visible) setLightboxOpen(false); }, [visible])` + reset in `runStatusChange` / `handleDelete`. |
| Row `accessible={true}` collapses Switch (a11y #4) | Remove `accessible={true}` from the row View. Give the Switch a richer `accessibilityLabel` that includes status + description + value, plus `accessibilityState={{ checked: value }}`. |
| Backdrop wins focus order (a11y #1) | Hide the backdrop Pressable from a11y; keep tap-to-dismiss as a pointer-only affordance. The labeled close button is the screen-reader path. |
| Card missing `accessibilityViewIsModal` (a11y #2) | Add the prop to FlagDetailModal card View. |

### PL8 — Edge cases + cleanup

| Finding | Fix |
|---|---|
| `searchQuery` persists (correctness #4) | `useEffect` to reset `searchQuery` + `filterCat` when `visible` flips to `false`. |
| Search maxLength + perf (edge cases #7) | `maxLength={200}` on TextInput. |
| Unicode NFC (edge cases #6) | Normalize both haystack and query via `.normalize('NFC')` before lowercasing in `searchFlags` + `tokenizeQuery`. |
| `DEFAULT_PREFS` shared ref (correctness #3) | `Object.freeze(DEFAULT_PREFS)` at module scope so accidental mutation throws in dev. Also return `{ ...DEFAULT_PREFS }` from `loadPrefs` for defense-in-depth. |
| Dead `notificationPrefs` state (edge cases #4) | Pass through to `NotificationPrefsModal` as `initialPrefs` so the modal can render the right values on first paint without waiting for its own load. |

### PL9 — Copy + contrast polish

| Finding | Fix |
|---|---|
| Footer `#888` fails AA (a11y #7) | `#5b6470` (4.6:1). |
| Caption duplicates Image label (a11y #6) | Hide PhotoLightboxModal caption from a11y. |
| `notifyOnOpen` description (correctness #5) | Reword to "Notify when a flag returns to Open status (e.g., resolution rolled back)." |
