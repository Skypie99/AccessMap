### Tier1-4 — ScreenHeader title fit (M18) · `7919c68` + calibration `c18403b`
**File:** `src/components/ui/ScreenHeader.tsx`
- RNW does not implement `adjustsFontSizeToFit`, so (per the item's decision rule) went straight to the deterministic estimate-then-correct sizer: `onLayout` measures the title's `flex:1` slot; `estimated = len × titleSize × CHAR_WIDTH_RATIO × min(fontScale,1.3)`; if it overflows, `renderSize = max(floor(available/estimated × titleSize), round(titleSize×0.6))`; converges in one step (slot is invariant to fontSize). Native `adjustsFontSizeToFit` + `minimumFontScale={0.6}` kept as a backstop. Named constants + beginner comments.
- **Calibration (live-render, delta below): `CHAR_WIDTH_RATIO` 0.58 → 0.50.** At 375, "Review barriers" (30pt) measures **219px** and its slot is **241px** — 0.58 over-estimated (261px) and false-shrank it to 27px. 0.50 → estimate 225px < 241px (no false shrink) yet > the ~186px slot at 320 (still shrinks to fit).
- **Evidence:** **375 WEB-CONFIRMED** — title renders full **30px**, `scrollW == clientW` (not truncated), no false shrink. **320:** deterministic + native-correct (slot 186 < natural 219 → renders 24px, natural@24 = 175 ≤ 186 → fits). RNW's `onLayout`-on-`<Text>` timing prevented observing the 320 shrink live in the preview (it fires at mount on native with the final Yoga slot); **flagged for device.**

## Implementation delta worth Sky's eye — safe-area context read (Tier1-5)

The item's recipe was "add `useSafeAreaInsets` + hook". That hook **throws** `"No safe area value available"` when there's no `SafeAreaProvider` — and the modal **render-tests** (which are *outside* this branch's fence, so I can't edit them) mount these sheets without one. It red-ed 12 tests. I switched all six sheets to read `SafeAreaInsetsContext` directly with a zero fallback:

```ts
const insets = React.useContext(SafeAreaInsetsContext) ?? { top: 0, bottom: 0, left: 0, right: 0 };
```

`SafeAreaInsetsContext` has a `null` default (non-throwing); under the app's real provider it returns identical insets. This keeps everything inside the fenced source files (no test/setup edits) and is strictly more robust. Full suite went back to green.
