Accessibility (built in, not bolted on)
---------------------------------------
- Each row is grouped (accessible) with a composed label that includes
  the color name — meaning is never carried by color alone.
- Section headers ("Severity", "Categories") use accessibilityRole
  "header".
- Decorative glyphs are hidden from the screen reader.
- Close button is a full-width 44pt+ target.
- Trigger button has both label ("Map legend") and hint ("Opens a
  guide explaining flag categories and severity").
- Sheet has maxHeight 85% with internal ScrollView so content survives
  large dynamic type.
