## What each branch does

### F2 Onboarding flow (`feat/onboarding-flow-2026-05-24`)
First-launch tutorial — 3 swipeable cards (report flagging · verify others · earn points) shown above the auth gate the first time the app opens. Skip button always visible; Back/Next/Get Started bottom row. Sets `@accessmap/onboarded_v1` after completion so it never shows again. Coexists with the existing per-user `OnboardingModal` (which is post-auth and per-user — different layer).

**Polish (PL-F2 — 3 HIGH a11y):**
- `accessibilityViewIsModal` on overlay (VoiceOver no longer escapes to auth screen)
- Respects `useReduceMotion` — disables swipe animation when OS reduce-motion is on; buttons still drive navigation
- Removed `accessible={true}` wrapper that was swallowing inner `accessibilityRole="header"`; card position now announced via `AccessibilityInfo.announceForAccessibility` + visible "Card N of 3" label

### F3 Settings hub + About (`feat/settings-hub-2026-05-24`)
New 4th tab consolidating: Notification preferences · Help & FAQ · What's New · Send feedback · My feedback history · About AccessMap · Sign out. Existing modals are imported & rendered (not modified). About is a modal sheet showing app version, tagline, credits, and a plain-language privacy summary.

**Polish (PL-F3 — 1 HIGH + cross-cutting):**
- New `src/lib/confirm.ts` — platform-aware confirm helper (web uses `window.confirm`, native uses `Alert.alert`). Settings sign-out now routes through this — was silently unreachable on web before (3rd `Alert.alert`-no-op trap this cycle after R8 + R11)
- About modal card sets `accessibilityViewIsModal` (focus containment)
- Hero emoji also marks `importantForAccessibility="no-hide-descendants"` for Android TalkBack
- Sign-out row's `accessibilityHint` now signals destructive intent (was color-only — invisible to SR users)

### F4 Filter presets manager (`feat/filter-presets-manager-2026-05-24`)
Modal + storage layer for saving named filter presets (categories + severity + status). Manager UI complete: list, rename, delete (with confirm). Per-user storage at `@accessmap/filter_presets_v1:<userId>`, cap 20, oldest-trim. **Apply-to-map wiring deferred to next cycle** — `MapScreen.tsx` is held by the parked R8 branch.

**No polish needed** — Alex called F4 "the reference pattern the other two should copy" for its correct use of `accessibilityViewIsModal`. The pure lib has 18 tests covering all CRUD operations + IO defenses + cap edges.
