## Intent items with NO implementation in either lineage

1. **(q) Keyboard appearance** — no `keyboardAppearance` prop on any `TextInput` in B33 or MAIN; the keyboard theme is purely system-driven. (Keyboard *avoidance* is implemented; keyboard *appearance* is not.)
2. **(k) Glass-material pin callout** — the native callout is deliberately opaque `color.surface` in both (`PlatformMap.tsx:681-684` B33 / `:627-630` MAIN); no glass callout variant exists. Only the Details sheet is glass.
3. **(j) Red error-banner clearance** — the red `errorBanner` (`backgroundColor: color.error`) is never measured into `chromeInsetTop`; a callout can still open under it in both lineages (B33 only measures the command bar + denied-location banner).
4. **`glassMode.ts`** — the named artifact does not exist in either lineage; Reduce-Transparency handling lives in `src/lib/accessibility.ts:526-540` + `GlassSurface.tsx:207-240` (functionally covered, file absent).
5. **(h) `ScreenHeader` compaction** — the shared header primitive's own height (`ScreenHeader.tsx:241`) is unchanged in both; reclaim is achieved only by per-screen top padding.
6. **(l) Address-search magnifier** — `AddressSearchModal` has no icon beside its input in either lineage (title text only), so "icon aligns with Search" is only verifiable on the Map command bar and the Tasks field.
