## Loop-by-loop record

### Loop 1 — Live open-flag count badge on Tasks tab

**Branch:** `feat/tasks-tab-badge-2026-05-23`  
**Files:** `src/screens/TasksScreen.tsx`

### Loop 2 — Relative timestamps ("2h ago") in Task cards and Nearby list

**Branch:** `feat/relative-timestamps-2026-05-23`  
**Files:** `src/lib/relativeTime.ts` (new), `src/lib/__tests__/relativeTime.test.ts` (new),
`src/screens/TasksScreen.tsx`, `src/screens/NearbyFlagsModal.tsx`

**How to try:** Tasks tab → any card shows "2h ago" or similar instead of a bare date.

### Loop 5 — "Mine / All" toggle in TasksScreen

**Branch:** `feat/tasks-my-flags-toggle-2026-05-23`  
**Files:** `src/screens/TasksScreen.tsx`

**What:** Two chips (Mine / All) appear above the flag sections when there are flags in the
list. "Mine" narrows the list to flags reported by the current user; "All" restores the full
view. Client-side filter on the already-loaded data — no extra fetch.

**How to try:** Tasks tab → tap "Mine" to see only your own reports.

### Loop 6 — Sort controls in MyReportsModal (Newest / Oldest / Severity)

**Branch:** `feat/my-reports-sort-2026-05-23`  
**Files:** `src/components/MyReportsModal.tsx`

**What:** Three sort chips (Newest / Oldest / Severity) appear when the list has more than
one report. "Newest" keeps the server-default DESC order. "Oldest" and "Severity" apply a
client-side sort via useMemo. Active chip is highlighted blue. Chips are accessible
(role=button, selected state).

**How to try:** Profile tab → My Reports (with 2+ reports) → tap "Severity" to see worst
issues first; tap "Oldest" to see your earliest reports.

---

### Loop 7 — Category filter chips in NearbyFlagsModal

**Branch:** `feat/nearby-filter-2026-05-23`  
**Files:** `src/screens/NearbyFlagsModal.tsx`

**What:** A horizontally-scrollable chip bar appears between the modal header and the flag
list when the list contains flags in more than one category. Each chip shows the category name
and a count. Tapping a chip narrows the distance-sorted list; tapping the active chip or "All"
resets. Empty state message adapts to the active filter.

**How to try:** Map tab → Nearby (list icon) → if multiple categories appear, use the chips
to filter to e.g. "No Ramp" only.

### Loop 8 — Severity description hint in ReportFlagModal

**Branch:** `feat/severity-hint-2026-05-23`  
**Files:** `src/screens/ReportFlagModal.tsx`

**What:** A live hint line appears below the 1–5 severity buttons showing the label (e.g.
"Moderate") and plain-English description (e.g. "Hard for many users."). Updates immediately
when you tap a button. `accessibilityLiveRegion="polite"` lets screen readers announce the

**How to try:** Report a flag → tap each severity button — the description updates instantly
below the row.

### Loop 10 — "Clear all watched flags" with confirmation

**Branch:** `feat/watched-clear-all-2026-05-23`  
**Files:** `src/components/MyWatchedModal.tsx`, `src/lib/watchedFlags.ts`
