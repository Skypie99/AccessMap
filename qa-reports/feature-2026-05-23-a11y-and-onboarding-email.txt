1) Auto-open accessible list when a screen reader is on (Phase 2)
   Branch: feat/auto-open-list-a11y-2026-05-23
           (stacked on feat/nearby-flags-list-2026-05-23 — merge that first)
   Commit: 5bf753b  Auto-open NearbyFlagsModal when a screen reader is on
   Files:  +57 against the nearby-flags branch (new src/lib/accessibility.ts
           + ~16 lines added to MapScreen.tsx)

   A tiny useScreenReader() hook reads AccessibilityInfo.isScreenReaderEnabled()
   and subscribes to screenReaderChanged for live updates. MapScreen uses
   it to auto-open NearbyFlagsModal once per mount when VoiceOver/TalkBack
   is detected — so blind/low-vision users land directly in the navigable
   linear view instead of the visual map. If they explicitly close it,
   we leave them on the Map; the "📋 List" FAB remains as manual re-entry.

2) First-run Onboarding cards
   Branch: feat/onboarding-cards-2026-05-23  (independent, off main)
   Commit: 95e7059  Add first-run OnboardingModal (3 swipeable cards)
   Files:  +315 / -2 (new src/lib/onboarding.ts + src/screens/OnboardingModal.tsx
           + App.tsx tweak)

   Three swipeable cards shown on first sign-in: 📍 Welcome / what flags
   are, 🎯 Severity 1-5 (with note that meaning is carried by color AND
   number), ⭐ Earn points. Pagination dots, Next button, "Get started"
   on the last card, Skip top-right. Persisted per-user via AsyncStorage
   (already installed for Supabase auth — no new dependency). Each card
   reads as one composed sentence to a screen reader.
