═══ STAGE 4 — BLINDED PERSONA BASELINE READS (01_baseline-reads.md) ═══
Fresh parallel agents, ZERO project context, given ONLY capture files (+ a flow-ordered file list). Their unprimed reactions are first-class evidence — bank them verbatim, one section per reader, appended as each lands. Personas (all six):
- R1 — wheelchair user planning a route around barriers (gets the FIND-flow sequence + map/state shots): can I find, judge, and trust a route? What would strand me mid-journey?
- R2 — blind, VoiceOver-primary user (gets the a11y-tree dumps FIRST, then the same screens' PNGs in order): walk both flows from the tree — what does this app SAY? Is the map usable non-visually at all? Name every unlabeled, mislabeled, or ambiguous node.
- R3 — low-vision, large-type user (gets the DT-proxy shots + their standard-size pairs): what breaks, clips, or vanishes as type grows? Where does contrast hurt?
- R4 — one-handed / limited-dexterity user (gets size-labeled base + flow shots): reach map per device size; which targets look small or crowded; which gestures scare me (pinch? drag? long-press?).
- R5 — senior mobile craft reviewer (gets the full base set, both themes): cohesion, premium, trust — where does the material system sing, and where does it crack?
- R6 — first-time user under cognitive load (gets onboarding + FIND + CONTRIBUTE sequences): do I understand what this is, what severity means, what happens when I submit, within seconds per screen?
